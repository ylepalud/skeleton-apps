# 0019. Everything written in English

- Status: accepted
- Date: 2026-10-23

## Context

The repository is public and serves as a template for other projects.

## Options

- English for code, comments, docs, commits and pull requests
- The author's language for docs and commits

## Decision

Chosen: English for code, comments, docs, commits and pull requests.

## Consequences

- Anyone can read and reuse the repository and its generated projects.
